# Manufacturer Brand Logos Directory

This directory holds official manufacturer logo files for **Goodwill Electrical World**.

## File Naming Convention
Save logo files using the exact brand slug format:
- `/public/brands/cera.svg`
- `/public/brands/finolex.svg`
- `/public/brands/goldmedal.svg`
- `/public/brands/jaquar.svg`
- `/public/brands/lt.svg`
- `/public/brands/legrand.svg`
- `/public/brands/parryware.svg`
- `/public/brands/philips.svg`
- `/public/brands/supreme.svg`
- `/public/brands/apl-apollo.svg`
- `/public/brands/tata-pipes.svg`
- `/public/brands/johnson.svg`
- `/public/brands/aaa.svg`
- `/public/brands/tms.svg`

## Format & Quality Specifications
1. **Preferred Format:** Vector SVG (`.svg`) for maximum sharpness at any resolution.
2. **Alternative Format:** Transparent PNG (`.png`), minimum resolution of **400x200 pixels**.
3. **Fallback:** If a logo file is missing or fails to load, the system automatically displays a high-contrast text wordmark fallback (`TEXT-XL FONT-BOLD TRACKING-TIGHT TEXT-[#070F1A]`).
